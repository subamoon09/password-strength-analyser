# Password Strength Analyzer

## Overview
The Password Strength Analyzer is a Python-based security tool that evaluates the strength of user-entered passwords.

It checks:
- Password length
- Uppercase and lowercase characters
- Numbers
- Special characters
- Common password usage
- Password reuse prevention using SHA-256 hashing

---

## Features
✅ Password strength evaluation  
✅ Suggestions for stronger passwords  
✅ Common password detection  
✅ Password reuse prevention  
✅ SHA-256 hashing for secure storage  

---

## Technologies Used
- Python
- Regular Expressions (`re`)
- SHA-256 Hashing (`hashlib`)
- JSON File Handling

---

## How It Works
1. User enters a password.
2. The system checks:
   - Length
   - Character complexity
   - Common password usage
   - Reuse of old passwords
3. The tool displays:
   - Password strength
   - Improvement suggestions
   - A stronger sample password
